# Política de Seguridad de mUzVidX

## Versiones Soportadas

Actualmente se brinda soporte de seguridad a las siguientes versiones de la aplicación:

| Versión | Soportada |
| :--- | :--- |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Compromiso con la Privacidad y Seguridad

mUzVidX es un proyecto open source centrado en la libertad del usuario, la reproducción multimedia de alta fidelidad y el respeto a la privacidad:
- **Sin Claves Privadas**: El repositorio no contiene credenciales maestras, tokens de autenticación de pago ni llaves privadas.
- **Sin Telemetría**: La aplicación no recolecta telemetría ni rastrea la actividad de navegación ni reproducción del usuario.
- **Seguridad en Descargas**: Todas las conexiones remotas de streaming y descargas utilizan protocolos HTTPS cifrados.

## Reporte de Vulnerabilidades

Si descubres una vulnerabilidad de seguridad en mUzVidX:

1. **No abras un Issue público** para reportar fallos de seguridad críticos o fuga de datos.
2. Abre un **Security Advisory** privado directamente desde la pestaña **Security** del repositorio en GitHub, o contacta a los mantenedores vía correo electrónico o mensaje privado.
3. Incluye:
   - Descripción detallada del problema.
   - Pasos para reproducirlo o prueba de concepto (PoC).
   - Impacto potencial en los usuarios o el dispositivo.
   - Modelo de dispositivo y versión de Android probada.

Agradecemos tu colaboración responsable para mantener este proyecto seguro para toda la comunidad.
